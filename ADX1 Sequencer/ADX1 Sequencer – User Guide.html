MAM ADX1 Sequencer

VST3 / AU MIDI Sequencer Plugin  ·  User Guide

The ADX1 Sequencer is a MIDI step sequencer built specifically for the MAM ADX1 analogue drum synthesiser. It sends MIDI notes and CC messages to control all eight voices, with deep per-step programming, pattern management, LFO modulation, and global swing.

Installation

macOS

Copy the plugin files from this folder to the standard Audio Plug-In directories:

  • VST3 → ~/Library/Audio/Plug-Ins/VST3/
  • AU (Audio Unit) → ~/Library/Audio/Plug-Ins/Components/

After copying, rescan plugins in your DAW. In Ableton Live, go to Preferences → Plug-Ins and click Rescan. In Logic Pro, AU plugins are detected automatically on next launch.

⚠️ The plugin is a MIDI Effect — route it on a MIDI track pointed at your ADX1. In Ableton, place it on an Instrument track with the ADX1 as the output device. In Logic, insert it as a MIDI FX on an External MIDI track.

CL/OP pairs share a voice on the ADX1. CL closes the voice, OP leaves it open. Only the CL lane in each pair has a CC assignment. All MIDI is sent on Channel 1.

Transport

Play / Stop

Click PLAY to start the sequencer. The button toggles to STOP while playing. Click STOP to stop and hold position.

The sequencer syncs to host tempo and transport automatically — when your DAW is playing, the ADX1 Sequencer follows. Manual play/stop is available when the DAW is stopped.

BPM

Drag the BPM slider or click the number field and type a value (20–300 BPM). When the host is running, the displayed tempo tracks the DAW automatically.

Tap Tempo

Click TAP repeatedly in time to set the BPM. Taps older than 3 seconds are discarded. Three or more taps are averaged for accuracy.

Global Swing

The SWING button enables a universal swing that overrides the individual per-lane swing values. Drag the slider to set the amount (0–100%). When disabled, each lane uses its own swing setting independently.

Pattern Banks & Patterns

The sequencer has 4 banks (A–D) each containing 8 patterns — 32 patterns in total. Click a bank letter to switch banks, then click a pattern number to select that pattern.

Pattern switches queue until the next bar boundary (every 4 global steps) so changes are always in time. The queued pattern flashes purple. The active pattern is shown in amber.

Use COPY and PASTE to duplicate patterns between slots. CLEAR ALL erases all steps in the current pattern.

The Sequencer Grid

Each row is one voice lane. There are 32 steps per lane, grouped into 8 bars of 4 steps. Alternating bars have a slightly different shade to aid navigation.

Activating Steps

Left-click any step cell to toggle it on or off. An active step shows a green velocity bar. An empty step is dark.

Velocity

Each step has up to 4 sub-step velocity bars (depending on subdivision count). The bar height represents the velocity (1–127). Scroll the mouse wheel over a substep to adjust its velocity. Hold Shift for coarser steps.

Subdivisions

Right-click any active step to open the subdivision menu. Choose x1 (single hit), x2, x3, or x4 to split the step into equal sub-hits. Each sub-hit has its own velocity bar.

Probability

Each step fires conditionally based on its probability value (0–100%, default 100%). Alt + Scroll on a step adjusts its probability. The value is shown in amber inside the step cell when it's below 100%.

Microtiming

The thin bar at the top of each step controls microtiming. Drag it left or right to nudge the step's hit time within the step window (±50%). Blue means early, amber means late. The position snaps to musical grid points: ±50%, ±33%, ±25%, ±16%.

Track Length

Each lane can have an independent step count (1–32). Drag the vertical handle on the right side of the step grid to shorten or lengthen the lane. Shorter lanes loop faster, creating polyrhythmic patterns.

Swing (per lane)

Each lane has its own swing control in the panel to the left of the steps. Drag up/down on the swing area to set the amount (0–100%). Swing delays every odd-numbered step. Swung steps get a pink border.

Enabling Global Swing in the transport bar overrides all per-lane swing values with a single shared amount.

Randomization

Each lane has a ⚄ (dice) button on the right side. It has two functions:

  • Left-click — immediately randomizes the lane using the current config
  • Right-click — opens the randomize config panel (shown right)

Config Panel

Toggle which parameters get randomized:

  • Steps (on/off) — randomly activates steps based on the density setting
  • Velocity — assigns random velocities to active steps
  • Subdivisions — randomly sets x1–x4 (weighted toward x1)
  • Probability — assigns random probability values (biased toward 100%)
  • Microtiming — adds random micro-offsets (25% chance, snapped to grid)
  • Swing — randomizes the lane's swing amount

Density slider controls how many steps are activated when "Steps" is enabled — from sparse (low %) to dense (high %).

Click Randomize now inside the panel to apply with the current settings.

LFO Modulation

The plugin includes 5 independent LFOs that can modulate the CC outputs of any voice. Switch to the LFOs tab to configure them.

Per-LFO Controls

ControlDescription
ON toggleEnable or bypass this LFO
ShapeSine, Triangle, Square, Saw, or Random
TargetWhich CC to modulate (Bass/Synth/Snare/HiHat/Metal, or off)
DepthModulation amount (0–127). Depth 64 = ±64 around the manual CC value
FREE / SYNCFree rate in Hz (0.01–20 Hz), or tempo-synced division
Rate / DivisionIn FREE mode: frequency in Hz. In SYNC mode: 1/32 to 8 bars
Waveform displayLive preview of the LFO shape and current phase position (amber line)
When an LFO is active and targeting a CC, it overrides the manual CC slider for that voice. The manual value is used as the centre point for the modulation.

CC Manual Control

At the bottom of the Sequencer tab, five horizontal sliders set the manual CC values for each voice (CC 102–106). These control parameters such as decay, tune, or filter on the ADX1 — the exact mapping depends on your ADX1 patch.

When an LFO targets a CC, the LFO modulates around this manual value. If no LFO is active on a channel, the manual value is sent directly every block.

Saving & Loading

All pattern data, LFO settings, CC values, bank/pattern selection, and global swing are saved with your DAW project automatically via the standard VST3/AU state mechanism. No separate preset files are needed.

Use your DAW's native preset system to save and recall configurations independently of a project.

Tips & Tricks

  • Use different track lengths across lanes to create evolving polyrhythms — a 14-step bass against a 16-step hi-hat creates a pattern that repeats every 112 steps.
  • Set low probability on fill hits to add organic variation without fully randomizing a pattern.
  • Use the CL/OP pairs (Snare, HiHat, Metal) to layer closed and open articulations on the same voice. Stagger them with microtiming for flam effects.
  • Randomize with only Velocity enabled (Steps off) to humanize an existing groove without changing which steps fire.
  • Use LFO on Synth (CC 103) with a slow Sine at low depth for subtle pitch/timbre wobble.
  • Copy a pattern to an empty slot before randomizing so you can easily revert.
