MAM ADX1 SEQUENCER

STEP SEQUENCER PLUGIN FOR THE MAM ADX1 ANALOGUE DRUM SYNTHESIZER

A MIDI step sequencer built specifically for the MAM ADX1. Programs all eight voices with per-step velocity and subdivision, individual lane lengths for polyrhythms, swing, probability, microtiming, pattern banks, chain mode, and a chaos randomizer.

VST3 AU macOS 11+ Ableton Live Logic Pro Any DAW

Installation

VST3 — Ableton Live, Bitwig, Reaper, etc.

Copy ADX1 Sequencer.vst3 to:

~/Library/Audio/Plug-Ins/VST3/

Rescan plugins in your DAW after copying.

AU — Logic Pro, GarageBand, etc.

Copy ADX1 Sequencer.component to:

~/Library/Audio/Plug-Ins/Components/

Logic detects it automatically on next launch.

Both files are ad-hoc signed. On first open macOS may block them — go to System Settings → Privacy & Security and click Open Anyway.

DAW Setup

Ableton Live (VST3)

  1. Create a MIDI track
  2. Drop ADX1 Sequencer into the instrument slot from the VST3 browser
  3. Open the plugin UI — find the MIDI OUT row near the top
  4. Click ↻ to refresh the device list, select your ADX1's MIDI port
  5. Press Play in Ableton — the sequencer starts and sends MIDI directly to the ADX1
The plugin bypasses Ableton's MIDI routing entirely via the built-in MIDI OUT selector. No second track or MIDI From routing needed.

Logic Pro (AU)

  1. Create a Software Instrument track
  2. In the instrument slot load External Instrument, point it at your ADX1's MIDI port and channel 1
  3. In the MIDI FX slot (above the instrument), insert ADX1 Sequencer
  4. Press Play in Logic
You can also use the plugin's built-in MIDI OUT selector in Logic, same as Ableton — no External Instrument needed.

Other DAWs (Reaper, Bitwig, etc.)

Insert the VST3 on any MIDI track. Use the built-in MIDI OUT selector to send directly to the ADX1. The sequencer syncs to the host transport automatically.

Transport & BPM

  • PLAY / STOP — starts/stops the internal sequencer. When loaded in a DAW, the sequencer syncs to the host transport automatically and ignores the internal buttons.
  • BPM slider & display — drag or click to type. Range 20–300 BPM. Overridden by host tempo in a DAW.
  • TAP — tap repeatedly to set BPM by feel. Averages the last few taps.
  • SWING / slider — global swing that overrides all per-lane swing settings when active. Toggle on (purple) to enable.

MIDI Output

The MIDI OUT selector sends notes directly from the plugin to a CoreMIDI device — no DAW routing needed.

  • Click ↻ to refresh the connected device list
  • Select your ADX1's USB MIDI port from the dropdown
  • The selection is saved with the project and reconnects automatically

Sequencer Grid

Step editing

  • Left-click — toggle a step on/off (velocity 100 by default)
  • Right-click — open the step popup: set subdivisions (1–4 hits per step) and probability (0–100%)
  • Scroll wheel on an active step — adjust velocity (1–127)
  • Alt + click on any step — set that lane's loop end to that step (polyrhythm length)

Microtiming

  • Shift + drag left/right on a step — adjust microtiming offset (±50% of a step)
  • Shift + scroll on a step — snap through the microtiming preset values
  • Shift + double-click — reset microtiming to 0
  • The thin bar at the very top of each step shows the current offset (amber = late, blue = early)

Subdivisions & Probability (right-click popup)

  • 1 2 3 4 — split a step into that many evenly-spaced hits, each with its own velocity
  • Probability slider — chance the step fires on any given pass (0–100%). Steps below 100% show an amber badge. An active step at 60% shows 60% at the bottom of the cell.

Zoom

Use the − / + buttons below the pattern bar, or Cmd + scroll, or pinch on a trackpad. Range: 100–400%.

Bar separators

Bars alternate between lighter and darker backgrounds. A thin vertical line marks every bar boundary. The header row shows bar numbers.

Lane Controls

Lane length (polyrhythms)

Alt + click any step to set that lane's loop length to end at that step. The amber bracket on the last active step shows where the loop ends. Lanes with different lengths loop independently — a 12-step bass against a 16-step hihat creates an evolving polyrhythm.

Swing (per lane)

Each lane has a swing slider in the label area. Odd-numbered steps are pushed later. Drag right to increase. The global SWING button overrides all per-lane swing when active.

Mute (M button)

  • Click M on any lane to mute it — steps are silenced but remain visible at reduced opacity so you can see what would be playing
  • Click M in the header row above the mute column to mute all lanes at once — click again to unmute all
  • Mute state is per-pattern and saved with the project

Randomize (⚄ button)

  • Left-click ⚄ — randomize this lane immediately using its config settings
  • Right-click ⚄ — open the randomize config panel: choose which parameters to randomize (steps, velocity, subdivisions, probability, microtiming, swing) and set density (0–100%)

Clear lane (× button)

Clears all steps on that lane. CLEAR ALL in the pattern bar clears all lanes and resets all per-lane swing to 0.

Pattern Banks

4 banks (A–D) × 8 patterns = 32 patterns total, all saved with the project.

  • Click a bank button (A/B/C/D) then a pattern number (1–8) to switch patterns
  • Pattern switches happen at the next bar boundary — if you're on bar 2 of a 4-bar pattern, the switch happens when bar 3 would start
  • A pattern button glows purple while a switch is queued
  • COPY / PASTE — duplicate the current pattern to any slot

Pattern Length

The − BARS + control sets the global pattern length (1–8 bars = 4–32 steps). The grid resizes automatically. Each lane's individual loop length still runs independently within this global length.

Randomize All + Chaos

The RANDOM slider and RAND ALL button work together to generate full patterns in one click.

  • Set the RANDOM slider to choose the style
  • Click RAND ALL to instantly generate a new pattern at that style

Pattern Chain

Chain mode plays patterns in a sequence automatically.

CHAIN ON → A1 ▶ A2 B1 A3 ← drag to reorder · right-click to remove · click to jump
  • Click CHAIN to enable chain mode
  • Click pattern number buttons to append entries to the chain
  • Drag pills left/right to reorder
  • Right-click a pill to remove it
  • Click a pill to jump to that pattern (queues at next bar boundary)
  • The active pill shows a progress bar along its bottom edge and a triangle arrow below it
  • CLR clears the chain. Toggle CHAIN off to return to manual switching.
Bank colours: A = green, B = blue, C = amber, D = purple.

Tips

  • Polyrhythms: Alt+click to set different lane lengths — Bass at 12, HiHat at 16, Metal at 10 creates a pattern that won't repeat for 60 steps.
  • Fills: Copy a pattern, paste it to the next slot, add extra hits, chain them together for automatic fill drops.
  • Variation without changing the pattern: Set key steps to 80% probability — every pass sounds slightly different.
  • Live arrangement: Build a chain of 8 patterns for a full song structure, click pills during playback to jump sections.
  • Swing feel: Enable Global Swing at 20–35% for a classic analogue drum machine shuffle. Per-lane swing lets you drag individual instruments independently.
  • Microtiming: Shift+drag the snare slightly late (+10–15%) for a behind-the-beat pocket. Shift+drag the bass slightly early (−5%) to push the groove forward.
  • Chaos starting points: Hit RAND ALL with chaos at 10% for an instant conventional groove, then nudge steps and velocities by hand.
  • Mute soloing: Mute All (header M button), then unmute individual lanes to audition them in context. Muted lanes stay visible so you can reference what's there.
