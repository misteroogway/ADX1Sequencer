MAM ADX1 SEQUENCER

STEP SEQUENCER PLUGIN FOR THE MAM ADX1 ANALOGUE DRUM SYNTHESIZER

A MIDI step sequencer designed specifically for the MAM ADX1. Programs all eight voices with per-step velocity and subdivision, per-lane swing and length, LFO CC modulation, multi-pattern banks, and a pattern chain mode for live arrangement.

VST3 AU macOS 11+ Ableton Live Logic Pro

Installation

VST3 — Ableton Live, Bitwig, etc.

Copy ADX1 Sequencer.vst3 to:

~/Library/Audio/Plug-Ins/VST3/

Then rescan plugins in your DAW.

AU — Logic Pro, GarageBand, etc.

Copy ADX1 Sequencer.component to:

~/Library/Audio/Plug-Ins/Components/

Logic will detect it automatically on next launch.

Both files are unsigned (ad-hoc signed). On first open macOS may show a security warning. Go to System Settings → Privacy & Security and click Open Anyway.

DAW Setup

Ableton Live

The plugin includes a built-in MIDI OUT selector. No special routing is needed — just drop it on a track and pick your ADX1's MIDI port directly in the plugin UI.

Any MIDI track ADX1 Sequencer (instrument slot) → open UI → pick MIDI port
  1. Create a MIDI track
  2. Drop ADX1 Sequencer into the instrument slot
  3. Open the plugin UI — find the MIDI OUT row near the top
  4. Click ↻ to refresh the device list, then select your ADX1's MIDI port
  5. Press Play in Ableton — the sequencer starts and sends directly to the ADX1
The plugin syncs to Ableton's transport automatically. You don't need to press Play inside the plugin — just use Ableton's play button.

Logic Pro

Software Instrument MIDI FX: ADX1 Sequencer → External Instrument → ADX1 port
  1. Create a Software Instrument track
  2. In the instrument slot, load External Instrument and point it at your ADX1's MIDI port, channel 1
  3. In the MIDI FX slot (above the instrument), insert ADX1 Sequencer
  4. Press Play in Logic — the sequencer drives the External Instrument which forwards to the ADX1
In Logic you can also use the plugin's built-in MIDI OUT selector instead of the External Instrument — same approach as Ableton.

Sequencer Grid

Basic step editing

  • Left-click a step to toggle it on/off at default velocity (100)
  • Right-click a step to open the velocity & subdivision menu
  • Steps alternate between lighter and darker bars — each group of 4 steps is one bar
  • The white outline moves through the grid as the sequencer plays

Subdivisions

Right-clicking a step lets you split it into up to 4 sub-hits within the same step duration. Each sub-hit has its own velocity. Use this for rapid rolls, ghost notes, or flam-style accents.

Swing per lane

Each lane has a swing slider on the left. Odd-numbered steps are pushed slightly later. Higher values = more pronounced shuffle feel. The label shows the current swing amount.

Lane length

Each lane has an independent step count (drag the handle on the right of each lane). A lane with fewer steps than the global pattern length will loop within the pattern — great for polyrhythmic patterns.

Probability

Right-click any step and set a probability from 0–100%. Steps set below 100% will randomly skip on some passes, adding variation without changing the pattern.

Microtiming

Right-click a step and nudge its timing forward or backward by up to ±50% of a step duration. Use sparingly for a human feel or to compensate for hardware latency.

Randomize (⚄)

Each lane has a dice button (⚄) on the right. Left-click to randomize immediately. Right-click to open the randomize settings panel where you can control density and which parameters get randomized (steps, velocity, subdivisions, probability, microtiming, swing).

Zoom

Use the − / + buttons in the tab bar, or pinch on a trackpad, or Cmd + scroll to zoom the grid. Zooming makes individual steps wider and easier to click.

Transport & BPM

  • PLAY / STOP — starts and stops the internal sequencer. When loaded in a DAW, the sequencer syncs to the host transport automatically — you don't need to press these.
  • BPM slider & display — drag the slider or click the number to type a value (20–300 BPM). Overridden by the host tempo when in a DAW.
  • TAP — tap repeatedly to set BPM by feel. Averages the last few taps.

Global Swing

The SWING button and slider in the transport row apply a master swing amount across all lanes simultaneously, overriding their individual per-lane swing settings.

  • Click SWING to toggle global swing on (purple) or off
  • Drag the slider to set the swing amount (0–100%)
  • When off, each lane uses its own independent swing setting

MIDI Output

The MIDI OUT row lets you route the sequencer directly to your ADX1 without any DAW routing configuration.

  • Click ↻ to refresh the list of connected MIDI devices
  • Select your ADX1's MIDI port from the dropdown
  • The selection is saved with your project and reconnects automatically
  • In Logic, you can use either the built-in MIDI OUT selector or the External Instrument approach — not both at the same time
If your ADX1 doesn't appear in the list, make sure its USB cable is connected and the device is powered on, then click ↻ to refresh.

Pattern Banks

There are 4 banks (A–D) × 8 patterns each = 32 patterns total, all saved with your project.

  • Click a bank button (A/B/C/D) to switch banks
  • Click a pattern number (1–8) to switch patterns
  • When playing, pattern switches happen at the next pattern boundary (seamless, no glitches) — the button glows purple while queued
  • COPY / PASTE — copy the current pattern and paste it to any other slot
  • CLEAR ALL — erase all steps in the current pattern

Pattern Length

The − BARS + control sets how many bars the pattern is (1–8 bars = 4–32 steps). The sequencer grid resizes to show exactly that many steps. Each lane's individual length still loops independently within this global length.

Pattern Chain

Chain mode lets you sequence patterns to play one after another automatically — useful for arranging a full song or live performance set.

CHAIN ON → A1 ▶ A2 B1 A3 ← progress bar fills as pattern plays

Building a chain

  1. Click CHAIN to enable chain mode (button turns blue)
  2. Click pattern numbers (1–8) to append them to the chain — each click adds one pill
  3. You can add the same pattern multiple times
  4. Drag pills left or right to reorder the chain
  5. Right-click a pill to remove it from the chain
  6. Click CLR to clear the entire chain

Playback

  • The currently playing pattern is highlighted with a bright outline and a progress bar that fills across the bottom of the pill as the pattern plays
  • A small triangle arrow below the active pill shows which pattern is current
  • Click any pill to jump to that pattern immediately (queued at the next pattern boundary)
  • When the chain is disabled, normal manual pattern switching resumes
Bank colours: A = green, B = blue, C = amber, D = purple. You can tell at a glance which bank each chain entry comes from.

LFO Modulation

Click the LFOs tab to access 5 LFO channels, each of which can modulate one of the ADX1's CC parameters.

  • Shape — Sine, Triangle, Saw, Square, Random (S&H)
  • Target CC — select which CC the LFO controls (102–106)
  • Depth — how much the LFO modulates the CC value (0–127)
  • Rate — either free-running Hz or tempo-synced (1/32 – 8 bars)
  • Enable — toggle each LFO independently

When an LFO is active on a CC, it overrides the manual CC slider for that channel. The CC slider is still visible as a reference baseline.

CC Modulation

The CC MODULATION section at the bottom of the Sequencer tab has 5 sliders for manual control of the ADX1's continuous controllers.

Tips & Tricks

  • Polyrhythms: set different lane lengths — e.g. Bass at 16 steps and HiHat at 12 steps — for evolving patterns that drift in and out of phase
  • Fills: use Copy to duplicate a pattern, then add extra hits on the copy for a fill version, chain them together
  • Variation: add 80% probability to ghost notes and hi-hat shuffles — the pattern sounds different every pass
  • Live arrangement: build a chain of 8 patterns for a full song structure, click pills during playback to jump sections
  • Swing: enable Global Swing and set it to ~20–35% for a classic analogue drum machine feel
  • Microtiming: nudge the snare slightly late (+10–15%) for a dragging, behind-the-beat groove
